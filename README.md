# Go AFK

*(Repository and code name: DigitalRewards.)*

Kids earn gaming time with physical activity: every qualifying minute of activity
(logged on Apple Watch) buys gaming minutes, 10 by default. Game time is enforced
on Windows PCs and iPhone/iPad. Parents set the rules in Parent mode of the iPhone
app. No servers: all data syncs through the family's iCloud accounts (CloudKit).

See [docs/SPEC.md](docs/SPEC.md) for the full spec and plan.
