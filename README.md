# DigitalRewards

Kids earn gaming time with physical activity: every qualifying minute of activity
(brisk walk or above, logged on Apple Watch) buys 10 minutes of gaming. Game time
is enforced on Windows PCs and iPhone/iPad, with Android to follow. Parents set
the rules in a parent app. No servers: all data syncs through the family's iCloud accounts (CloudKit).

See [docs/SPEC.md](docs/SPEC.md) for the full spec and plan.
